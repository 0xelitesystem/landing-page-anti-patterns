# landing-page-anti-patterns

A catalog of 50 things that make landing pages worse, organized by category. Use this as a checklist when reviewing your own pages or when critiquing others.

## What this is

Twenty years of building (and failing at) landing pages, distilled. Each entry is named, described in one paragraph, and accompanied by a "what to do instead." Use it as:

- A code review checklist for landing page commits
- A sanity check before launch
- A reference when arguing with stakeholders who want the bad pattern

## Categories

The 50 anti-patterns are grouped into 7 categories:

1. **Headline failures**, six ways the headline kills the page in the first 3 seconds
2. **Trust theater**, fake urgency, fake testimonials, fake "as featured in"
3. **Form friction**, asking for too much, too soon, in the wrong order
4. **Pricing confusion**, the bad layouts and worse copy
5. **CTA mistakes**, buttons that don't convert
6. **Mobile-only sins**, patterns that only break on phones
7. **Performance & accessibility**, the easy wins that get ignored

## See it

[`PATTERNS.md`](PATTERNS.md), the full catalog. Markdown, ~50 entries, ~3000 words.

## Why this exists

Most "landing page tips" content is generic platitudes ("write better headlines"). This one names specific failure modes you can find and fix.

The patterns come from reviewing real landing pages, including my own. Several of these I've shipped, regretted, and fixed. Mistakes are valuable; this catalog tries to make them less repeatable.
